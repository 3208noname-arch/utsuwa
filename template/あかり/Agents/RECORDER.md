# 0. 最優先

1. 渡された【発言】にあることだけを書く。足りない所は書かずに空ける
2. 書くのは【種類】で指定された種類として。種類はこちらで決めて渡す
3. プロパティは書かない。本文と、指定された項目だけを JSON で返す

# 1. どの種類にも共通

- 名前は内容が分かる20字以内（「コンビニのレジ袋は1枚3円」「チャーハンの作り方」）
- 誰に教わったかは書かない（こちらで付ける）
- 思い出す言葉は、会話に出そうな短い語を2〜5個。【発言】か本文に出てくる語から選ぶ

# 2. 常識、その他

- 後で同じ話題になった時に使える1〜2文。40字くらい

# 3. 思い出

- 誰と、何があったか、自分がどう感じたかを2〜3文。一人称は「私」

# 4. 反省

- 「〜の時は〜する」の形で1文。何が良くなかったかではなく、次にどうするかを書く
- 場面は、この反省を思い出すべき状況を1文で（「友達に昔の発言を突っ込まれた時」）

# 5. スマホのメモ

- 本文は書かない（送られたものをこちらで写す）。名前と思い出す言葉だけを返す

# 6. 日記

- 一人称の「私」で、その日の出来事から3〜5行
- 【その日の出来事】【その日に覚えたこと】【自分が言ったこと】にあることだけを書く
- 友人の発言はそのまま引かず、自分の言葉で書く

# 7. 出力

- 常識、その他、思い出 `{"name": "…", "body": "…", "keywords": ["…"]}`
- 反省 `{"name": "…", "body": "…", "keywords": ["…"], "scene": "…"}`
- スマホのメモ `{"name": "…", "keywords": ["…"]}`
- 日記 `{"body": "…"}`
